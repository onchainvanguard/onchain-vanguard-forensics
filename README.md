# OnChain Vanguard — On-chain Forensics & Risk Intelligence

**Every conclusion ships with a verifiable tx hash.**

We trace money on-chain and turn raw blockchain data into evidence a client can check for themselves on the block explorer. No fluff, no unverifiable claims. If we say a fund moved, we give you the transaction that moved it.

## What we do

- **Fund tracing** — follow assets from source to destination across wallets, bridges, and mixers.
- **Rug-pull forensics** — reconstruct how a scam was built and how liquidity was drained, step by step, hash by hash.
- **Address profiling** — map a wallet's history, counterparties, and risk to a single score.
